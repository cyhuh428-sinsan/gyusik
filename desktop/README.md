# 규식이 Windows 설치형 (Electron)

폐쇄망(인터넷이 없는 망)에서도 쓸 수 있는 설치 파일입니다. 웹 화면과 같은 코드를 앱 안에 넣어 두고 `app://gyusik/` 주소로 제공하므로, 설치한 뒤에는 서버도 인터넷도 필요 없습니다.

## 만드는 법

```bash
npx gulp deploy                 # 저장소 루트에서: build/ 에 웹 배포본 생성
cd desktop
npm install                     # Electron, electron-builder
npm run dist                    # dist/ 에 설치 파일 생성
npm run smoke                   # 앱을 창 없이 실행해 자동 점검 (JSON 한 줄 출력, 통과하면 종료 코드 0)
```

결과물 (`desktop/dist/`):

| 파일 | 용도 |
|---|---|
| `Gyusik-<버전>-x64.exe` | 설치 파일 (일반 PC, Intel/AMD 64비트). **관리자 권한 없이** 사용자 계정에 설치됩니다 (한 번 클릭 설치) |
| `Gyusik-<버전>-arm64.exe` | 설치 파일 (Windows on ARM, 예: Snapdragon PC) |
| `Gyusik-<버전>-x64.zip`, `-arm64.zip` | 설치 없이 풀어서 실행. 보안 검토용 사본에 편합니다 |
| `Gyusik-<버전>-x64-portable.exe` | **설치 없이 더블클릭으로 실행**하는 한 파일(x64). USB나 공유 폴더에서 바로 실행할 때 편합니다 (`npm run dist:portable`로 이 파일만 만듭니다) |

## 포터블 실행 파일

- 설치도 관리자 권한도 필요 없습니다. 실행할 때마다 임시 폴더에 풀어서 시작하므로 설치판보다 첫 화면이 몇 초 늦을 수 있습니다.
- 설정과 저장한 패턴은 설치판과 같은 사용자 폴더(`%APPDATA%`)에 저장됩니다. 다른 PC에서 쓰려면 내 패턴 화면의 내보내기·가져오기를 사용하세요.
- 관리자 정책(`%ProgramData%Gyusikpolicy.json`)은 포터블에서도 똑같이 적용됩니다.

## 폐쇄망 반입 안내

- 설치 파일 하나만 반입하면 됩니다. 설치와 실행에 인터넷이 필요 없습니다.
- 코드 서명이 되어 있지 않아 Windows SmartScreen이 경고할 수 있습니다. 기관의 보안 절차에 따라 서명하거나 예외 처리하세요.
- 구성 요소와 라이선스: 규식이(GPL-3.0, RegExr 기반), Electron/Chromium(`LICENSES.chromium.html`), PCRE2(BSD, `site/deploy/libpcre2.wasm`). 소스는 `SOURCE.txt` 참조.
- 업데이트는 새 설치 파일을 반입해 덮어 설치합니다. 자동 업데이트는 없습니다.

## 외부 통신 정책

**기본값은 "아무것도 밖으로 보내지 않음"** 입니다. 앱 안의 모든 요청 가운데 `app://` 이외의 것은 차단되고, 예외는 하나뿐입니다. 사용자가 설정 화면에 직접 입력한 AI 서버 한 곳(한국어 문장으로 만들기)입니다.

관리자는 `%ProgramData%\Gyusik\policy.json` 에 정책 파일을 둬서 이를 더 좁힐 수 있습니다(`policy.example.json` 참조).

```json
{ "blockExternal": true, "allowedHosts": [] }
```

| 항목 | 뜻 |
|---|---|
| `blockExternal: true` | 앱이 어떤 요청도 밖으로 보내지 않습니다. AI 기능이 꺼지고 설정 화면의 스위치는 사용자가 바꿀 수 없습니다 |
| `allowedHosts: ["host:port"]` | 사용자가 AI 서버로 지정할 수 있는 곳을 이 목록으로 제한합니다 |
| 파일 없음 | 기본값 적용 |
| 파일이 깨져 읽을 수 없음 | **외부 통신을 막는 쪽**으로 처리합니다 |

## 보안 구성

- 화면은 샌드박스와 컨텍스트 격리 안에서 실행되고 Node 기능에 접근하지 못합니다. 앱 안의 파일만 제공하며 상위 폴더 접근은 차단됩니다.
- 권한 요청(카메라, 위치 등)은 모두 거부하고, 다른 주소로 이동하거나 새 창을 여는 것을 막습니다.
- AI 키는 Windows 사용자 계정으로 암호화해 저장합니다(Electron safeStorage). 저장하지 않으면 앱을 닫을 때 사라집니다.
- 브라우저 엔진의 백그라운드 통신(구성 요소 업데이트 등)은 끕니다.
- 서버가 필요한 RegExr의 기능(계정, 커뮤니티)은 들어 있지 않습니다.

## 알려진 한계

- 앱 아이콘은 아직 기본 Electron 아이콘입니다.
- 설치 파일을 실제로 실행해 설치해 보는 시험은 하지 않았습니다. 패키징된 앱(`dist/win-unpacked/규식이.exe`)은 `--smoke` 점검을 통과했습니다.
- Windows 10 이상 64비트(x64)와 ARM64용입니다. **32비트(x86) Windows는 지원하지 않습니다.** Electron 44부터 32비트 빌드가 제공되지 않으며, 32비트를 위해 이전 버전(43)에 머물지 않기로 했습니다.

규식이 기능 구조와 화면 구성안

한국어로 배우고, 만들고, 보고, 고치는 정규식 도구입니다. 인터넷 환경과 폐쇄망 모두에서 쓰며, 핵심 기능은 인터넷 없이 동작합니다.

기반 RegExr 3.8.0 포크 (GPL-3.0) 엔진 1차 JavaScript · PCRE2 배포 인터넷은 웹 · 폐쇄망은 Windows 설치형 주소 gyusik.sinsan.kr

해결할 문제

아래 번호는 이 문서 전체에서 각 기능이 어떤 문제를 푸는지 표시하는 데 씁니다.

  1. ①한국어로 된 사이트가 없다
  2. ②설명이 명확하지 않고 어렵다
  3. ③쉽게 만들도록 돕는 기능이 없다 (설명·오류 알림·추천·생성)
  4. ④시각적인 표현이 부족하다
  5. ⑤학습·생성·시각화·디버깅이 흩어져 있다
  6. ⑥인터넷이 없는 폐쇄망에서도 써야 한다

기능 구조

상단 메뉴는 네 가지 모드입니다. 모든 모드가 하나의 패턴과 테스트 케이스를 함께 쓰기 때문에, 어느 모드에서 만든 결과든 다른 모드로 그대로 넘어갑니다.

오프라인 인터넷 없이 동작 온라인 전용 인터넷 또는 AI 서버 연결 필요 2차 2차 범위 제안

모든 화면에 공통

  • 상단 바: 모드 전환, 엔진 선택, 연결 상태 표시
  • 설정: 설명 수준(입문·실무), 기본 엔진, 테마, 글자 크기
  • 설정 > AI: 연결 방식, 제공자, 모델, 추론 등급, 연결 확인 온라인 전용
  • 관리자 설정: 외부 통신 완전 차단과 허용 주소 목록, AI 설정 고정
  • 정보: RegExr 기반 표기, GPL-3.0 고지, 소스 받는 곳
  • 업데이트: 폐쇄망은 업데이트 파일 반입 자동 업데이트는 온라인

  1. 1엔진 선택. JavaScript와 PCRE2(2차에 Python). 엔진을 바꾸면 진단을 즉시 다시 해서 문법 차이를 알려줍니다. ③⑥
  2. 2연결 상태. 오프라인 모드일 때 누르면 지금 쓸 수 없는 온라인 전용 기능 목록이 나옵니다. ⑥
  3. 3패턴 편집기. 그룹마다 색을 고정해서 패턴, 선로도, 결과, 설명에서 같은 색으로 보입니다. 플래그는 기호와 뜻을 함께 표시합니다. ②④
  4. 4한 줄 요약. 패턴 전체를 한국어 한 문장으로 요약합니다. 입문은 쉬운 말, 실무는 용어를 씁니다. ①②
  5. 5시각화. 선로도가 기본이고, 2차에 엔진이 한 단계씩 움직이는 모습을 보여주는 단계 실행을 추가합니다. ④
  6. 6연동 강조. 패턴, 선로도, 결과, 설명 중 한 곳에 마우스를 올리면 나머지 세 곳의 같은 부분이 함께 강조됩니다. 그림은 그룹 2를 가리킨 상태입니다. ④⑤
  7. 7테스트 영역. 텍스트, 테스트 케이스(일치해야 함 / 일치하면 안 됨), 치환, 추출을 탭으로 나눕니다. ③
  8. 8한글 NFD 감지. 자모가 분리된 한글을 찾아 알려주고 한 번에 바꿔줍니다. 한국어 사용자만 겪는 문제입니다. ①
  9. 9도우미 패널. 설명은 토큰마다 한 줄씩 풀이하고, 각 줄의 "배우기"를 누르면 해당 강의로 이동합니다. ②⑤
  10. 10진단 문구 형식. 무엇이 문제인지, 왜 문제인지, 어떻게 고치는지를 순서대로 쓰고 바로 고치는 버튼을 둡니다. ②③
  11. 11상태 표시줄. 일치 수, 실행 시간, 백트래킹 위험, 테스트 통과 수를 늘 보여줍니다. ③④

  4. 4관리자 차단. 외부 통신 차단 설정이 켜져 있으면 연결 시도 자체를 하지 않습니다. 보안 심사 증빙에 씁니다. ⑥
  5. 5요청마다 바꾸기. 설정의 기본 모델과 추론 등급으로 시작하고, 결과가 아쉬우면 여기서 바꿔 다시 만듭니다. 관리자가 고정했다면 바꿀 수 없습니다. ③

작성 도우미 규칙

진단과 추천은 패턴을 구조로 분석한 뒤 규칙을 적용하는 방식이라 AI 없이 오프라인에서 동작합니다. 1차에 넣을 규칙 후보와 안내 문구 예시입니다.

종류감지 예안내 문구 (무엇이 · 왜 · 어떻게)
오류 범위 순서[z-a]범위가 거꾸로 되어 있습니다. 앞 글자가 뒤 글자보다 앞서야 합니다. → [a-z]
오류 엔진 차이(?P<year>\d{4})PCRE2·Python의 이름 붙은 그룹 문법이라 JavaScript에서는 오류가 납니다. → (?<year>\d{4})
경고 이스케이프www.naver.com.은 아무 글자 하나와 일치해서 wwwXnaver.com도 걸립니다. → www\.naver\.com
경고 범위 실수[A-z]대문자와 소문자 사이의 기호 6개([ \ ] ^ _ `)까지 포함합니다. → [A-Za-z]
경고 한글 범위[가-힝]힝 뒤의 6글자(힞~힣)가 빠집니다. 완성형 한글 전체는 → [가-힣]
경고 우선순위^a|b$"a로 시작" 또는 "b로 끝남"으로 해석됩니다. 둘 중 하나와 전체가 일치하게 하려면 → ^(a|b)$
경고 앵커 없음\d{3}-\d{4}일부만 맞아도 통과해서 abc123-4567xyz도 걸립니다. 입력값 검증용이면 → ^\d{3}-\d{4}$
경고 성능 위험(a+)+$반복 안에 반복이 있어, 일치하지 않는 긴 입력에서 처리 시간이 폭증합니다. 같은 뜻으로 → a+$
추천 간단한 표기{1,} {0,1}같은 뜻의 짧은 표기가 있습니다. → + ?
추천 엔진 맞춤[0-9]JavaScript에서는 \d와 같습니다. Python의 \d는 다른 나라 숫자도 포함하므로, 엔진이 Python이면 이 제안을 하지 않습니다.

규칙만으로는 사용자의 의도를 알 수 없습니다. 의도와 다른 결과는 테스트 케이스의 실패로 잡습니다. 그래서 예시로 만들기, 테스트 케이스, 테스트 문자열 제안이 한 흐름으로 이어집니다.

  • 서버 경유에 등록할 모델과 모델별 허용 추론 등급: 중계 서버를 구현할 때 결정. Gemini·Upstage의 OpenAI 호환 주소와 각 제공자의 추론 등급 값은 공식 문서로 확인
  • 인터넷 버전 사용 통계: 넣을지 여부. 넣더라도 폐쇄망 빌드에서는 제외
  • 설명 수준 기본값: 입문과 실무 중 처음 실행할 때의 기본값
